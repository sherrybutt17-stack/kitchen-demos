Kitchen remodeling · three brands · 21 pages

Three websites. Three agencies.
One brief.

Each of these is a complete seven-page site with its own brand, positioning, customer, colour system, typography, layout philosophy and conversion strategy. No CSS, JavaScript or design token is shared between them — the divergence is the point.

These cards open the source sites. The GoHighLevel-ready versions live in dist/ — same pages with all CSS, JavaScript and images inlined as base64, so each file pastes into a GHL Custom HTML block with nothing external to upload. Rebuild them any time with python3 scripts/build.py.
